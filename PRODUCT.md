# Perspectives gallery

Public, static gallery for source-informed design prototypes. Visitor opens Archive, selects Welcome a guest, tries four scenes, reads context and sources, then downloads SVG artwork or JSON study data.

## Audience and purpose

Curious visitors, designers and collaborators compare approaches to one shared task. Specific accounts inform playful interpretation; no scene represents a whole culture. Gallery supports future site and video production through portable public assets.

## Current scope

- Archive: one published study, Welcome a guest.
- Study: four interactive SVG scenes with reversible action and Reset.
- Evidence: documented account, design interpretation, uncertainty, source links and checked date.
- Comparison: shared aim, differences and takeaway question.
- Exports: current scene SVG and complete public study JSON.

Pilot remains hand-authored. Community review not recorded; sources provide context, not endorsement.

## Delivery

GitHub Pages serves plain HTML, CSS, browser JavaScript, JSON and local fonts. Relative paths support project hosting. No build step, backend or model calls. Public repository contains presentation code and selected publishable study data only. Private research logs, credentials, owner decisions, moderation and internal mapping stay outside gallery.

## Durable constraints

Preserve established Perspectives paper/green/Mozilla brand. Keep source context adjacent to prototypes, uncertainty explicit, controls keyboard reachable and motion respectful of reduced-motion preference. Claims require specific source scope. New studies must remain portable static data and assets.

## Success

Visitor can reach study from Archive, try and reset each scene, inspect evidence, compare four approaches and download usable SVG plus JSON. No login, generation service or private workflow required.
