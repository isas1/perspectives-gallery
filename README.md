# Perspectives gallery

## [Open gallery →](https://isas1.github.io/perspectives-gallery/)

**Archive → Welcome a guest → try four scenes.**

Public presentation code and selected source-informed prototypes only. No private research logs,
credentials, owner reviews, arm mapping or moderation records. No model generation runs here.

Edit `style.css` for design, `study.js` for interactions, `index.html` for archive and
`study.html` for the study page. Declarative public data: `studies/`. Native SVG downloads
and JSON data support future site and video production. SVG scenes are abstract interpretations;
source accounts never stand for whole cultures. Pilot is hand-authored; no community endorsement.

Run any static HTTP server locally. Every path is relative for GitHub Pages project hosting.
Mozilla fonts ship under their included OFL licenses; application code MIT (LICENSE).

## Automatic shelf

Private Perspectives archive publishes only allowlisted presentation data to `runs/` and
`runs.json`. Fixtures, held attempts and exact-content duplicates stay off this shelf.
The hand-authored four-country pilot remains a sample. Older method studies are explicitly
labelled ideas, not built cultural scenes. No private provenance, blind IDs, logs or reviews
travel with public outputs. `archive.js` draws the list; `run.js` draws archived results.
